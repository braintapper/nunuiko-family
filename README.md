# Nunuïko Family

Three font families built on [Nunito](https://github.com/googlefonts/nunito),
in one repo so changes stay consistent across them:

- **[Nunuïko](nunuiko/)**: rounded sans, from Nunito.
- **[Nunuïko Display](nunuiko-display/)**: from Nunito Sans.
- **[Nunuïkode](nunuikode/)**: Nunuïko made monospaced for code.

Each folder has its own README, build and proof. All three are licensed
under the SIL Open Font License 1.1 (see each folder's `OFL.txt`).
