# Nunuïko Family

Three font families built on Nunito and Nunito Sans, kept in one repo so
changes stay consistent across them:

- **[Nunuïko](nunuiko/)**: a rounded sans, derived from Nunito.
- **[Nunuïko Display](nunuiko-display/)**: derived from Nunito Sans.
- **[Nunuïkode](nunuikode/)**: Nunuïko made monospaced for code.

Each folder has its own build, glyph change log and license files.

## Proof

One page for all three families, regenerated with each font build and published
with GitHub Pages: **[https://braintapper.github.io/nunuiko-family/](https://braintapper.github.io/nunuiko-family/)**. Three tabs: **Family** compares the
families with each other, **Stock** compares each with the font it is derived
from (Nunuïko and Nunuïkode with Nunito, Nunuïko Display with Nunito Sans), and
**Code** compares Nunuïkode with Nunuïko and Cascadia Code. Switch any font on
or off; the fonts stack one above the next, or overlay. Open it on
[Nunuïko vs Nunito](https://braintapper.github.io/nunuiko-family/#stock/nunuiko),
[Nunuïko Display vs Nunito Sans](https://braintapper.github.io/nunuiko-family/#stock/nunuiko-display),
[the whole family](https://braintapper.github.io/nunuiko-family/#family/nunuiko,nunuiko-display,nunuikode) or
[Nunuïkode for code](https://braintapper.github.io/nunuiko-family/#code).

## Credits

Nunuïko Family is by Steven Ng. It stands on the work of the Nunito and
Nunito Sans designers:

- **[Nunito](https://github.com/googlefonts/nunito)** (base of Nunuïko and
  Nunuïkode) was designed by Vernon Adams, a well-balanced sans with rounded
  terminals. Its Cyrillic was added in 2017 by Manvel Shmavonyan and Alexei
  Vanyashin. Copyright 2014 The Nunito Project Authors.
- **[Nunito Sans](https://github.com/Fonthausen/NunitoSans)** (base of
  Nunuïko Display) was designed by Jacques Le Bailly (Baron von Fonthausen)
  as a sans with plain, unrounded terminals, from Vernon Adams's Nunito. Its
  contributors include Manvel Shmavonyan, Alexei Vanyashin, Marc Foley and
  Yanone. Copyright 2016 The Nunito Sans Project Authors.

Each family's `AUTHORS.txt` and `CONTRIBUTORS.txt` list everyone credited.
